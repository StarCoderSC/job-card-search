# Job Card Search

A local search page for the supplied village registration register.

## Structure

- `index.html` — page structure
- `style.css` — appearance
- `app.js` — search and UI logic
- `data.js` — extracted search data (1553 records)

The original HTML/MHTML file is **not** loaded by the website. The search only reads `data.js`.

## Run

Open `index.html` directly in a browser, or use Live Server while developing.

## Search

Type part of a person's name. Matching records show the Job Card Number and identifying details.

## Privacy

The dataset contains real people's information. Keep this project private/local and do not publish the repository or `data.js` publicly unless you have the necessary permission.
